## Visual Direction

- **Aesthetic:** Premium, modern Indian festive
- **Backgrounds:** Deep midnight purple + warm maroon
- **Accents:** Rich gold, amber, saffron (shared chroma & lightness, hue varies)
- **Typography:** Cormorant (elegant serif, headings) + Montserrat (modern sans, body)
- **Motion:** Diya flicker, cinematic card opening, floating golden particles, GSAP ScrollTrigger reveals, Framer Motion page transitions
- **Diya-inspired elements:** Glowing flame motifs, warm light falloff, decorative festive textures

## Sources Consulted

- PRD: `DiwaliWish — Personalized Diwali Wishes & Fun Predictions` (user-provided)
- ui-ux-pro-max design system search: `DiwaliWish personalized Diwali wishes festival Indian festive premium` — Cormorant/Montserrat pairing, scroll-triggered storytelling pattern, complex motion tier (8/10)
- Default aesthetic rules: 1–3 fonts, oklch accents sharing chroma/lightness, whites/blacks chroma ≤ 0.02
- anti-slop list: no gradient overload, no emoji-as-icons, no rounded cards with colored left-border strips, no hand-drawn complex SVGs
